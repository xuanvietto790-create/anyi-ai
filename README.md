# 安逸智能AI

独立的中文聊天网站，Python FastAPI 后端，HTML/CSS/JavaScript 前端。沿用简洁的聊天界面，主模型为 `deepseek-v4-pro`。

## 登录与注册

新增参考 DeepSeek 的独立登录页，支持密码登录、短信登录、短信注册、图形验证码刷新、发码倒计时、密码显示/隐藏与退出登录。

账号接口复用同工作区 `anyi-node` 的 `/api/auth/*`。Python 作为同源网关连接它；阿里云短信的发送、校验、频控、用户数据库与密码校验仍由 `anyi-node` 处理，没有在聊天项目中复制阿里云密钥或新增第二套账号库。

当前 `.env` 接入 `http://127.0.0.1:3000` 做本地联调，该 Node 服务配置为 `SMS_MODE=mock`。页面会明确显示模拟验证码与“未发送真实短信”。可以先注册并登录体验，已有本地安逸账号也可直接使用。

启用真实短信时，在 `anyi-node` 服务端配置它已有的阿里云 DYPNS 参数，并将 `SMS_MODE` 设置为 `aliyun`；部署后在聊天服务设置 `ANYI_AUTH_BASE_URL=https://正式域名`（也支持以 `/api` 结尾）。Python 正式远程账号地址要求 HTTPS。`ANYI_AUTH_ALLOW_MOCK=true` 仅允许 localhost 账号接口返回模拟码，远程地址始终过滤调试验证码。

登录后的聊天、附件、语音及上下文接口均需验证会话。浏览器只保存 HttpOnly 会话 Cookie；账号 access/refresh 凭证经加密保存在 `E:\Codex\work\anyi-ai-data\auth`，同目录的 `session.key` 需与会话数据库一同保留，不要提交到 Git。会话过期时自动刷新，退出后本地会话失效。

聊天记录按账号分别保存在浏览器 IndexedDB，附件在服务器按账号校验归属。旧版未登录记录仍保留在原位置；登录后可以通过提示主动导入，系统不会默认把旧记录归给任何账号。退出不会删除账号的本机历史，也不会自动把它显示给其他账号。

## 启动

进入本目录运行：

```powershell
powershell -ExecutionPolicy Bypass -File .\start.ps1
```

打开 http://127.0.0.1:8000 。首次运行会在 `E:\Codex\work\anyi-ai-venv` 创建虚拟环境并安装依赖，pip 缓存位于 E 盘，并检查中文语音模型与 V4 分词器（首次约下载 50 MB，全部位于 E 盘）。服务仅监听本机。已有虚拟环境时也可直接启动：

```powershell
E:\Codex\work\anyi-ai-venv\Scripts\python.exe -B -m uvicorn main:app --host 127.0.0.1 --port 8000
```

首次配置可将 `.env.example` 复制为 `.env` 并填写 API Key。已有 `.env` 无需覆盖。密钥仅在 Python 后端读取，Git 会忽略 `.env`。

## 已实现

- 流式回答，深度思考开关、可折叠的思考内容，停止生成与部分内容保留。
- Markdown 标题、列表、表格、引用、行内代码；代码高亮和一键复制代码；KaTeX 数学公式。
- 联网搜索开关，检索资料交给主模型回答，显示网页来源和可点击的引用编号。检索失败会明确提示；无结果时说明基于模型知识回答。
- 图片上传、粘贴图片、拖入文件、图片预览。图片由 `deepseek-flash` 识别，提取内容交给 Pro 回答。首次识别后缓存到 E 盘，后续追问复用描述；无法保证描述覆盖所有图片细节。
- PDF、DOCX、TXT、Markdown、CSV、JSON 和常见代码文件的内容问答。支持 UTF-8 和 GB18030 文本。
- 提问编辑：创建新分支并保留原对话；回答重新生成：保留旧版本，可前后切换。后续追问使用当前选中的回答版本。
- 历史全文搜索、按日期分组、重命名、删除和短时撤销；刷新恢复当前对话；导出 Markdown。
- 语音输入：浏览器只负责 MediaRecorder 录音，Python 使用 Vosk 本地识别中文，不依赖浏览器在线语音服务。支持上传 WebM、WAV、MP3、M4A、OGG 等录音，最长 90 秒、最大 12 MB。识别后填入输入框，由用户检查并发送。
- 回答朗读：默认使用 Python 调用 Windows 中文 SAPI 声音生成 WAV，由浏览器播放器播放；无需浏览器提供语音声音。支持暂停/继续、停止和调速，代码和表格跳过朗读。非 Windows 环境才尝试浏览器声音后备。
- 手机侧栏与遮罩、附件上传进度、加载/错误状态、键盘焦点、中文输入法 Enter 保护、Ctrl/Cmd + K 新建。
- 用户向上阅读时不自动滚到底部，提供回到最新消息按钮。

前端第三方依赖已保存在 `static/vendor/`，运行时无需访问 CDN。Markdown 输出经过 DOMPurify 清理，不执行模型返回的 HTML 脚本。

## 附件与存储

- 单条消息最多 4 个附件，单文件最大 10 MB。旧版每个对话 20 个附件的限制已移除，整体内容由 Token 窗口校验。
- 图片支持 PNG/JPEG/WebP/GIF，最长边 8192 像素。
- PDF 最多 1000 页；单个文档最多提取 100 万字符，超过时在附件上提示实际截取上限。旧附件仍保留上传时的提取文本，需重新上传才能取得更完整的内容。
- 扫描版/无文字 PDF 需要将页面作为图片上传；加密 PDF 需解密，旧 DOC 需另存为 DOCX。当前不做整本扫描 PDF OCR。
- 聊天记录、回答版本改存浏览器 IndexedDB，支持超出旧 localStorage 容量的长对话。升级时自动迁移旧记录，旧 localStorage 作为备份保留；模式偏好和当前对话 ID 仍存 localStorage。不跨设备同步。多标签页保存会合并不同对话，并记录删除状态。
- 附件原件、提取文本及图片描述保存在 `E:\Codex\work\anyi-ai-data\attachments`；临时上传文件位于 `E:\Codex\tmp\anyi-ai`。可用环境变量 `ANYI_DATA_DIR` 和 `ANYI_TEMP_DIR` 指定位置。
- 删除浏览器中的对话不会删除服务端附件，以免影响编辑分支和其他引用；本地附件上限 500 MB。清理附件目录会使已有图片预览和带附件的追问失效，请自行保留所需文件。
- 导出 Markdown 不包含附件原件；保存位置由浏览器下载设置决定。

## 1M 上下文

主模型接口报告的窗口为 **1,048,576 Token**。移除了旧版 80 条消息、单条 24000 字符、历史 120000 字符与附件总计 160000 字符限制。聊天请求仍有 1600 万字符的传输保护，输入框单次输入维持 16000 字符，不影响累计上下文。

后端按官方 V4 分词器统计历史、附件提取文本、系统提示与搜索资料，再为输出保留 8192 Token、协议误差保留 1024 Token；超过可用窗口会明确报错，不自动删去旧消息。输入框下方显示估算用量。API 流中返回的实际 usage 也会随该回答保存。1M 是单次对话的上下文总窗口，不代表跨对话的永久记忆。

分词器与 Vosk 中文模型位于 `E:\Codex\tool-cache\models`，缺失时运行 `python -B setup_assets.py`；启动脚本会自动执行。为了长对话页面流畅，界面先显示最近 80 条消息，可点击加载更早消息；发送给模型仍包含完整历史。

## 语音使用与限制

点击麦克风后允许浏览器录音，说完再次点击麦克风或“结束并识别”；文字出现后检查并发送。语音仅在本机 Python 服务中识别，不上传至浏览器厂商。普通话小模型对方言、噪声或专有名词可能识别不准，请检查文字。

如果内置浏览器拒绝麦克风：使用提示中的“上传录音识别”，或在系统 Edge/Chrome 通过 localhost / HTTPS 打开。本地识别可以解决浏览器语音云服务不通，但不能绕过浏览器或 Windows 的麦克风权限。

朗读默认使用 Windows 中文声音，若系统缺失中文语音包会明确提示。音频在 E 盘临时生成，返回后即删除；录音在内存中解码和识别，不留录音原件。实际声音播放仍取决于设备音量与浏览器自动播放策略，被阻止时显示“播放”供用户点击。

当前未接入单独的云端语音识别、实时双向语音通话、图片生成或跨设备云端历史同步。账号与附件鉴权已接入；公开部署时仍需配置正式账号服务、HTTPS、真实短信和按用户用量限制。

### 扫描 PDF 自动识别

PDF 优先提取文字层，文字稀少或无文字的页面使用本地 RapidOCR 中英文识别，结果按页标记 OCR，可能存在误字。单次最多 20 个 OCR 页面，超过需拆分；文字版仍支持最多 1000 页。加密 PDF 需先解密。上传仍限制每文件 10 MB；扫描清晰度与排版影响识别结果。识别引擎和模型安装在 E 盘虚拟环境，无需外部 OCR 密钥。
